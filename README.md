Este CRUD foi desenvolvido para consolidar conceitos de [ex: manipulação de DOM / Integração com API / Operações de Banco de Dados]. A aplicação permite que o usuário organize sua rotina de forma simples e intuitiva.

###  Funcionalidades (CRUD)

- **Create:** Adicionar novas tarefas à lista com título e [ex: data/prioridade].
- **Read:** Visualização clara de todas as tarefas cadastradas.
- **Update:** Possibilidade de editar o texto da tarefa ou marcar como "Concluída".
- **Delete:** Remover tarefas individualmente ou limpar a lista.
